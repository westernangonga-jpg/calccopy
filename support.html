CalcCopy Support

Use this page for installation help, troubleshooting, and issue reporting for CalcCopy — AI Calculations to Word.

Fastest fix first: reload CalcCopy from chrome://extensions, refresh the ChatGPT or Claude page, then capture the calculation again.

How to use CalcCopy

  1. Open a supported ChatGPT or Claude conversation containing a technical calculation.
  2. Open the CalcCopy side panel.
  3. Choose Capture full solution or select part of the response and choose Capture selection.
  4. Review the preview.
  5. Use Copy to Word for a quick transfer or Download Word file for the most consistent DOCX result.

Common issues

  • Nothing is captured: refresh the AI page after installing or updating CalcCopy, then try again.
  • Word formatting looks different after Ctrl+V: Microsoft Word versions handle browser clipboard math differently. Use Download Word file for the most reliable formatting.
  • Claude capture fails: refresh Claude and reselect the complete assistant calculation before capturing.
  • A complex operator displays differently in Word: confirm the downloaded DOCX first; Word rendering can vary between versions.

Report a problem

When reporting a problem, include:

  • CalcCopy version
  • Chrome version
  • Whether you were using ChatGPT or Claude
  • The exact action that failed
  • A screenshot if possible

Do not include passwords, account credentials, private API keys, or sensitive conversation content.

Privacy questions
