# CalcCopy GitHub Pages site

These files provide the public pages needed for the Chrome Web Store **Homepage URL**, **Support URL**, and **Privacy policy URL**.

## Publish with GitHub Pages

1. Create a **public** GitHub repository, for example `calccopy`.
2. Upload all files and the `assets` folder from this package to the repository root.
3. Commit the files to the default branch (usually `main`).
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then save.
7. Wait for GitHub Pages to publish.

If your GitHub username is `YOURNAME` and your repository is `calccopy`, use these Chrome Web Store fields:

- **Homepage URL:** `https://YOURNAME.github.io/calccopy/`
- **Support URL:** `https://YOURNAME.github.io/calccopy/support.html`
- **Privacy policy URL:** `https://YOURNAME.github.io/calccopy/privacy.html`

The Support page automatically points its **Open a GitHub support issue** button to the repository that hosts the GitHub Pages site.

## Important

Keep the site public and available while the Chrome Web Store listing is live. If CalcCopy's supported sites, permissions, analytics, accounts, payments, or data practices change, update `privacy.html` and the Chrome Web Store privacy disclosures at the same time.
